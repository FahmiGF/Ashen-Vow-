## 1. What the game is

- **Ashen Vow**: a browser **2D medieval dark-fantasy metroidvania / roguelite**, with a lot of side modes added on top (horror, 3D, MOBA, tower defense, naval, fishing, puzzle and so on).
- UI language: **Indonesian**. Tone: ash, oaths, fallen knights.
- **Version v0.35.0** (Update XXIV). Two later updates, XXV and XXVI, sit uncommitted in the working tree and have no version number yet.
- Repo `github.com/FahmiGF/Ashen-Vow-`, branch `main`.

### Tech stack and hard constraints
| Area | Choice |
|---|---|
| Runtime | Zero-build HTML5 Canvas + vanilla ES modules, no framework or bundler |
| Server | `server.js` (Node, zero dependencies) on `127.0.0.1:4300`: static files, `/ws` co-op WebSocket relay, `/admin` + `/api/*`, `/api/voice` ElevenLabs proxy |
| Simulation | Deterministic fixed step at 1/120 s. `src/core.js` is pure and never touches the DOM. `AshenGame.update(dt, input)` is the only gameplay entry point |
| Rendering | Procedural Canvas 2D for the main game. The 3D mode uses WebGL2 (PBR, GPU skinning, shadows, HDR, MSAA) with GLB assets generated by script, plus a Canvas fallback |
| Audio | Procedural WebAudio for SFX and music; no audio files. Voice: ElevenLabs (optional API key), then the browser's speechSynthesis, then subtitles only |
| Tests | `node --test`: **758/758 passing**. About 30+ CDP smoke scripts run in real Chrome |
| Saves | localStorage: `ashen-vow-progress-v1` (main, schema v2, with backup and quarantine copies), `-settings-v1`, `-character-v1`, `-horror-v1`, `-dread-v1`, `-veil-v1`, `-eternal-v1`, `-archive-v1`, `-3dhorror-v1`, `-hunter-v1`, `-secrets-v1`, `-voice-v1` |

## 7. Settings and system features
- **Settings 2.0**: 14 categories (graphics, display, audio, controls, gameplay, difficulty, accessibility, language, performance, interface, notifications, privacy, account, advanced), 148 settings, 6 graphics presets, 10 audio buses and 14 languages. Localization covers the settings shell only; RTL is supported.
- Search, Apply/Cancel, per-category reset, diagnostics, and a HUD Layout Editor.
- Rebindable controls with 2 slots per action and conflict swapping. Gamepad uses a fixed standard layout.
- **6 global difficulty profiles**: Story, Easy, Normal, Hard, Nightmare, Abyssal.
- Scary settings sit in their own screen (60+ settings). Anti-jumpscare and accessibility options can only remove effects, never add them.
- Debug: AI/Boss/Scary debug panel (`?dev=1` or F9), profiler (F3), and boot guard error codes BOOT-01 to BOOT-04.
- Shared engine pieces: NavGraph A*, EnemyBrain with a 12-state machine, a boss core (hitboxes, physics, phase controller), a QA release gate and a frame sampler.

## 8. Known gaps and honest limits (useful for planning)
1. **Overdrive's levels 201–300 are not playable yet.** Infinite Frontiers levels 101–200 are mostly data.
2. **Arc IV (The Rift) and Arc VI's Unwritten Expanse are locked teasers** with no content behind them.
3. Most enemies reuse about 7 AI archetypes. Bosses reuse pattern families; for example, Orsella reuses Vasska's attack machine.
4. Art is mostly procedural. There are no `.blend` sources, and the GLBs are generated by script. 12 environment packs have not been built.
5. Music is procedural with short loops. Voice depends on an ElevenLabs key or the browser's TTS.
6. There are no save slots: one browser profile holds all progress. There is no cloud save.
7. Co-op is a local relay with a host-authoritative model. There is no matchmaking or anti-cheat.
8. Seasonal events and the economy are local and offline.
9. Localization covers the settings screen only.
10. Some hardware/performance release gates have not been measured: low/medium/high profiling, memory soak, network load.
11. Navigation is crowded: the main menu has about 35 entries, plus many hubs and save keys.
12. Docs are out of date: `MASTERPLAN.md` still calls v0.14.0 the current release, CLAUDE.md §9 still says Cistern is "configuration only", and the Update XXV/XXVI work is not in the Update Log.
