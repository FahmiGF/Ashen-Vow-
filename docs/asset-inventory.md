## Honest limits

- The kit is authored procedurally by `tools/export-glb.mjs`; there is no Blender source file in the
  repository, so this inventory can only describe exported geometry, not editable .blend scenes.
- Materials are PBR metallic-roughness factors with no texture images; UVs exist but no texture atlas
  is bound yet.
- Low-detail variants are the `_LOD1`/`_LOD2` meshes plus the `_COL` proxy, not separate files.
- The gap list is deliberately conservative: if a prop is an exterior shell, it is not counted as an
  interior pack.
