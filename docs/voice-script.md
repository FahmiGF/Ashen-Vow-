# Ashen Vow: naskah suara boss (boss voice script)

Generated by `npm run voice:script` from the dialogue tables in `src/`. Do not edit by hand.

- **766 lines** across **146 bosses** (605 boss lines, 161 lines for the player character, The Oathbound).
- **Recorded so far: 0 / 766.** Any line without a recording plays a wordless cinematic sting under its subtitle.

## How to deliver a take

Save each take as `assets/voice/boss/<boss-id>/<key>-<n>.mp3` (OGG, WAV and M4A also work), mono, 44.1 or 48 kHz, peaks at about -3 dBFS, **dry**: no reverb or effects. The game adds pitch, weight, doubling and reverb per archetype, so a clean, close take sounds best. Then run `npm run voice:script` to refresh the manifest.
